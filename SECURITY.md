# Security Policy

## Scope
Meeting Summarizer Local processes UTF-8 transcript files locally. It makes no network requests, loads no plugins, executes no transcript content, and requires no credentials.

## Privacy
Transcripts are read only from paths explicitly supplied by the user. Reports are written only when `--output` is supplied. The project has no telemetry.

## Reporting
Please report security concerns privately through GitHub's security reporting features when available. Do not include confidential meeting transcripts in public issues.

## Safe use
Treat generated summaries as assistive output. Review action items and decisions against the source transcript before relying on them for consequential decisions.
